小白术语表

先理解意思，再记专业名称。

Parameter

参数

模型训练后学到的数值。7B 表示约 70 亿个参数。

Precision

精度

每个参数用多少 bit 存储。精度越低，显存越省。

KV Cache

聊天缓存

模型为了记住前文保存的中间结果。上下文越长、并发越高，通常越占显存。

Gradient

梯度

像老师批改作业，告诉模型哪些参数需要往哪个方向修改。

Optimizer State

学习记录

优化器保存历史更新信息，帮助模型决定下一步如何学习。

Activation

解题草稿

模型前向计算时产生的中间结果。训练时要保留，方便反向传播。

Quantization

量化

把 FP16 等高精度权重压缩成 INT8、INT4，以降低显存和计算成本。

Offload

卸载

把部分内容暂时放到 CPU 内存或硬盘，换取更低 GPU 显存占用，但通常会变慢。
