一张 GPU 大概能放下多大的模型？

下面主要比较模型本身的理论容量。真正运行时还需要给 KV Cache 和临时空间留余量。

GPU显存单卡大致可容纳适合什么
RTX 409024GB7B FP16；14B INT4个人开发、本地体验
RTX 509032GB14B FP16 较紧；32B INT4消费级大显存单卡
A100 / H10080GB32B FP16；70B INT8 较紧数据中心训练和推理
H200141GB70B FP16 的模型本身长上下文和大模型推理
B200192GB70B FP16，并有较多余量Blackwell 数据中心 GPU
B300288GB100B FP16；更大的量化 / MoE 模型Blackwell Ultra

B300 是什么？

B300 是单颗 Blackwell Ultra GPU，显存容量为 288GB。它仍然是一张 GPU 的概念。

GB300 NVL72 是什么？

它不是一张显卡，而是机架级系统：由 72 颗 GPU 和 36 颗 Grace CPU 组成，总 GPU 显存约 20TB。

快速判断方法：先算模型本身，再选择显存更大的 GPU，并留出运行空间。多卡总显存够用，只代表容量可能够，不代表一定能高效运行。
