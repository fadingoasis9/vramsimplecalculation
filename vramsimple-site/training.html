经验公式

全量训练（AdamW）

约 16 bytes / 参数 + 激活

  • 模型权重：2 bytes
  • 梯度：2 bytes
  • FP32 主权重副本：4 bytes
  • Adam 学习记录：8 bytes
70B 示例

一步一步算

参数量70B
每个参数约 16 bytes
仅参数相关状态70 × 16 = 1120GB ≈ 1.12TB
1.12TB 还没有算“解题草稿”（激活）、通信缓冲和显存碎片，所以实际全量训练往往需要更多显存。

怎么降低单卡压力？

把模型和学习记录拆到多张 GPU，或者放到 CPU / NVMe。常见方法包括 ZeRO、FSDP、张量并行和 Offload。

小白怎么理解？

不用先记技术名词，只要知道：多张卡可以分摊显存，但会增加通信和工程复杂度。
