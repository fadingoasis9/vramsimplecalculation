一张 GPU 大概能放下多大的模型？

先看显存容量，再看带宽、互联与软件支持。消费级 GPU 通常能看到官方购买入口；数据中心 GPU 多数需要联系 NVIDIA 或服务器厂商询价。

消费级 · 24GB

RTX 4090

理论上可放 7B FP16 或 14B INT4。适合本地开发、原型验证与单用户推理。

价格信息官方页面提供购买渠道；实际库存价因地区与停售状态变化。
官方规格 / 购买
消费级 · 32GB

RTX 5090

14B FP16 较紧，32B INT4 更合适。适合个人高端推理与视觉生成工作负载。

价格信息官方页面可查看建议售价、区域购买渠道与合作品牌。
官方规格 / 购买
数据中心 · 80GB

A100

32B FP16 权重可放入单卡；常见于已有训练集群、云服务与推理部署。

价格信息通常按整机、云实例或渠道报价，不提供统一公开零售价。
官方规格 / 询价
数据中心 · 80GB

H100

常用于大模型训练与高吞吐推理。真正优势还来自 NVLink / NVSwitch 与成熟的软件生态。

价格信息裸卡、HGX 服务器与云租赁价格差别很大，需按部署形态询价。
官方规格 / 询价
数据中心 · 141GB

H200

单卡可容纳 70B FP16 的模型权重，但仍需为 KV Cache 与运行空间预留显存。

价格信息主要通过服务器厂商、云平台和 NVIDIA 合作伙伴报价。
官方规格 / 询价
Blackwell · 192GB

B200

可容纳 70B FP16 并保留更多运行空间，面向高吞吐训练和推理集群。

价格信息B200 通常随 HGX / DGX 或整机系统采购，官方不列统一零售价。
HGX B200 官方页
Blackwell Ultra · 288GB

B300

更适合大型推理、MoE 与训练。注意 B300 是 GPU；GB300 是 Grace CPU 与 B300 GPU 组合的平台。

价格信息通过 GB300 / HGX / DGX 系统或合作伙伴询价，不按普通显卡零售。
GB300 官方页 / 询价
机架级系统 · 约 20TB

GB300 NVL72

包含 72 颗 Blackwell Ultra GPU 与 36 颗 Grace CPU，不是一张显卡。用于超大规模训练与推理。

价格信息按完整机架、网络、存储和服务方案报价，采购成本不能只看 GPU 数量。
官方系统页面
价格阅读提示：GeForce 页面通常有“购买渠道”或建议售价；A100、H100、H200、B200、B300 等企业级产品通常需要联系销售。服务器报价还会包含 CPU、内存、NVSwitch、网卡、存储、机柜、电力和服务。

显存够，不代表适合训练

训练还要看 BF16 / FP8 算力、HBM 带宽、NVLink / NVSwitch、网络拓扑和集群规模。

购买价，不等于使用成本

企业更关心每 token 成本、功耗、机房、网络、软件许可、运维和利用率。
